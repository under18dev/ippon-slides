# なぜ ippon か（Marp・Slidev・reveal.js との違い）

ippon は「1 枚 1 メッセージ」のスライドを、できるだけ少ない手間で作るための CLI です。
Markdown からスライドを作る道具はほかにもあります。このページでは、ippon が何を選び、
何を選ばなかったかと、ほかの道具のほうが向いている場面をまとめます。

## 1 枚 1 メッセージ（高橋メソッド）

ippon は [高橋メソッド](https://ja.wikipedia.org/wiki/%E9%AB%98%E6%A9%8B%E3%83%A1%E3%82%BD%E3%83%83%E3%83%89)
を前提にしています。1 枚のスライドには短い言葉を 1 つだけ、画面いっぱいの大きさで出します。
スライドは読ませる資料ではなく、話を後押しする合図です。箇条書きを詰め込みたくなったら、
それはスライドを分ける合図です。

そのため ippon には、テーマやレイアウトを選ぶ仕組みがほとんどありません。黒地に大きな文字という
1 種類の見た目を既定にし、書き始めてすぐ発表できることを優先しています。

## 着想元

ippon は Yusuke Wada さん（[@yusukebe](https://github.com/yusukebe)）の個人用のスライドアプリに
着想を得ています。それとは別の独立した実装で、持ち運べて、それだけで完結する
スライドに重きを置いています。

## ほかの道具との違い

| | ippon | Marp | Slidev | reveal.js |
|---|---|---|---|---|
| 書き方 | Markdown（独自の記法は少し） | Markdown | Markdown と Vue のコンポーネント | HTML（Markdown はプラグインで） |
| 出力 | HTML 1 ファイル、PDF、OGP 画像 | HTML、PDF、PPTX、画像 | Web アプリ、PDF、PPTX、PNG | HTML（PDF はブラウザの印刷で） |
| 見た目 | 1 種類。CSS 変数で調整 | CSS でテーマを作れる | テーマとレイアウトが豊富 | テーマとプラグインが豊富 |
| 必要なもの | Node.js だけ（依存ゼロ）。PDF は手元の Chrome | Node.js。PDF などは手元のブラウザ | Node.js のプロジェクト。書き出しに Playwright | ブラウザ（開発には Node.js） |
| 発表の補助 | 発表者ビュー、スマホのリモコン、タイマー | 発表者ビュー | 発表者モード、描画、録画 | スピーカービュー |

比較は ippon から見た大まかなものです。各ツールの最新の機能は公式のドキュメント
（[Marp](https://marp.app/)、[Slidev](https://sli.dev/)、[reveal.js](https://revealjs.com/)）を確認してください。

## ippon が向いているとき

- 言いたいことを 1 枚ずつ大きく見せたい（LT、勉強会、社内の発表など）。
- 資料を HTML 1 ファイルで配りたい。オフラインでも、何年後でも開けるようにしたい。
- プロジェクトを作らず、`npx` ですぐに使いたい。依存を増やしたくない。
- コードや API のレスポンスを見せたい（[コードのハイライト](syntax.md#コードブロック)、[`::http::`](http.md)）。
- スマホで操作しながら発表したい（[`ippon serve`](serve.md)）。

## ほかの道具が向いているとき

- 細かいレイアウトや図、アニメーションを作り込みたい → Slidev や reveal.js。
- PowerPoint（PPTX）のファイルで渡す必要がある → Marp や Slidev。
- 1 枚にたくさんの情報を載せた、読ませる資料を作りたい → Marp や、Google スライド・PowerPoint などのアプリ。

## ippon に入れないもの

- テーマやレイアウトの種類を増やすこと。見た目の調整は [CSS 変数](theming.md) の範囲にとどめます。
- ランタイムの依存パッケージ。PDF もブラウザを同梱せず、手元の Chrome を使います。
- 外部のサービス。発表者ビューもスマホのリモコンも、ブラウザと Node.js の標準機能だけで動きます。

> 迷ったら、足すのではなく削る。スライドからも、この道具からも。
