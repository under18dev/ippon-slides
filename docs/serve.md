# スマホをリモコンにする（`ippon serve`）

```sh
ippon serve slide.md
```

ローカルにサーバを立て、端末に **QR コード**を表示します。スマホのカメラで読み取ると
リモコン画面が開き、手元でスライドを操作できます。

## できること

- **ページ送り**（◀ ▶ / 最初 / 最後）
- **タイマーのリセット**と経過時間の確認
- **発表者ノートの確認**（`::note::` で書いた内容）

本番画面・発表者ビュー・スマホはリアルタイムに同期します。
Markdown（と `--css`）を保存すると、開いているデッキとリモコンが自動で再読み込みされます。

## 使い方

1. PC とスマホを**同じ Wi-Fi** に繋ぐ。
2. `ippon serve slide.md` を実行する。
3. 端末に出た QR をスマホのカメラで読み取る（または表示された URL を開く）。
4. PC では表示された `この PC で開く:` の URL をブラウザで開いて発表する。

QR は次の場所にも出ます。

- **発表者ビュー**（`p` キー）の右下。
- 本番画面で **`r` キー**を押すと QR を全画面表示（もう一度 `r` / `Esc` で閉じる）。

## コーディングエージェントと一緒に直す（`/__current-slide`）

`ippon serve` 中は、いまブラウザに表示しているスライドを `/__current-slide` で取得できます。
デッキ上で文字を選択しておくと、その文字列も返ります。

```console
$ curl -s http://localhost:3030/__current-slide
{
  "file": "/Users/you/talk/slide.md",
  "slide": 3,
  "total": 12,
  "lines": { "start": 21, "end": 30 },
  "source": "## 3 枚目\n\n- 説明がわかりにくい行\n...",
  "selection": "説明がわかりにくい行"
}
```

| キー | 中身 |
|---|---|
| `file` | Markdown の絶対パス |
| `slide` / `total` | 表示中のスライド番号（1 始まり）と枚数 |
| `lines` | そのスライドの Markdown 上の行範囲（1 始まり・両端を含む） |
| `source` | そのスライドの Markdown（`::note::` も含む） |
| `selection` | デッキで選択中の文字列（無ければ `""`） |

Claude Code などのコーディングエージェントにこれを読ませれば、ブラウザで文字を選んで
「ここ、もっと短く」と頼むだけで、エージェントが Markdown の該当箇所を見つけて直せます。
保存すればデッキは自動で再読み込みされ、同じスライドに戻ります。

エージェントに使い方を教えるには、スライドのあるディレクトリで次を実行します。

```sh
ippon skills init
```

`.claude/skills/ippon-slides/SKILL.md`（Claude Code）と `.agents/skills/ippon-slides/SKILL.md`（Codex など）が
置かれます。以後「ここ直して」と頼むと、エージェントは `ippon current` で表示中のスライドと選択中の文字列を読んでから
Markdown を直します。`ippon current` は起動中の `ippon serve` を自分で探すので、ポートを固定する必要はありません
（[CLI リファレンス](cli.md#current)）。

`/__current-slide` はトークン不要ですが、**この PC から `localhost` 宛てに来たリクエストだけ**に応えます
（スマホや LAN の他の端末からは読めません）。

## 仕組み

- 通信は **SSE（サーバ→クライアント）+ `POST /cmd`（クライアント→サーバ）** の小さな pub/sub だけ。
  WebSocket も外部サービスも使いません（ランタイム依存ゼロのまま）。
- 本番画面が「真実のソース」。スマホは状態を受け取って表示し、操作をサーバ経由で送ります。
- タイマーは端末間の時計ずれを避けるため、絶対時刻ではなく経過時間（elapsed）をやり取りします。
- 途中から繋いだスマホにも、直近の状態（現在のスライド・経過時間）がすぐ届きます。

## セキュリティ

- リモコンの URL には**ランダムなトークン**が付き、正しいトークンでないと
  デッキ・リモコン・配信（`/` `/remote` `/events` `/cmd`）にアクセスできません。
- `/__current-slide` はトークン不要の代わりに、この PC から `localhost` 宛てに来たリクエストだけを受け付けます
  （`Host` ヘッダーも確認し、外部サイトからの DNS リバインディングを防ぎます）。
- サーバは LAN に公開されます（画像などの静的ファイルはトークン無しで配信）。公開したくない
  ネットワークでは実行しないでください。

## オプション

| オプション | 意味 |
|---|---|
| `-p, --port <n>` | 待ち受けポート（省略時は空きポートを自動選択） |
| `--css <file>` | 追加の CSS |

終了は `Ctrl+C` です。

## うまく繋がらないとき

- **同じ Wi-Fi に繋がっているか**確認してください（スマホがモバイル回線だと繋がりません）。
- Wi-Fi の「**クライアント分離（AP isolation）**」が有効だと、スマホから PC に到達できません。
  ゲスト Wi-Fi などで起こりがちです。テザリングや別の Wi-Fi を試してください。
- ファイアウォールがポートをブロックしていないか確認してください。
