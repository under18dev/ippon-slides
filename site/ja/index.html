ippon は Markdown を「1 枚 1 メッセージ」のスライドに変換します。CSS/JS 全部入りの単一 HTML、そして 16:9 の PDF。ゼロ依存。ずっとあなたのもの。

はじめる GitHub でスター npx ippon-slides init

道具は消え、メッセージだけが残る。

名前の ippon（一本） は柔道で勝負を決める一本から。1 枚で 1 つのメッセージを決める。巧さは装飾ではなく引き算にあります。箇条書きが溢れたら、それはフォントを縮めるのではなくスライドを分ける合図です。

迷ったら、足すのではなく削る。スライドからも、この道具からも。

クラウドなし。専用ビューアなし。ランタイム依存なし。デッキはただの HTML ファイルで、どの端末でも、何年後でも開けます。

全部、1 ファイルに

厳選した機能だけ。ひとつひとつが居場所を持っています。

単一の自己完結 HTML

CSS も JS もインライン。メールでも Git でもオフラインでも開ける 1 ファイル。ビルドサーバも CDN も不要。--inline なら画像まで埋め込めます。

ランタイム依存ゼロ

ビルドに使うのは TypeScript だけ。PDF 出力はブラウザを同梱せずローカルの Chrome を直接駆動。

PDF と共有用の画像

--pdf でフォントも色もそのままの 16:9 PDF。ippon ogp で表紙を 1200×630 の画像にし、URL を貼ったときに表紙が出ます。

スマホがリモコン

ippon serve が QR を表示。読み取ればページ送り・タイマー・発表者ノートを手元で。LAN 上で動き WebSocket 不要。保存すると、開いているデッキがちらつかずに最新になります。

HTTP プレイグラウンド

::http:: で実レスポンス（ステータス・時間・ヘッダー・整形 JSON）をビルド時に焼き込み（CORS 無関係）＋ライブ再送信。

拡大とスポットライト

画像やコードをクリックで拡大。行をクリックすると周囲が暗くなり 1 行だけ強調。コード解説に最適。

発表者ビュー

p で現在・次のスライド、発表者ノート、タイマーを別ウィンドウに。両画面は同期。

テーマ変更

--css で少数の CSS 変数を上書き。既定のままですぐ発表に臨めます。

背景画像と 2 カラム

::background:: でスライドの背景に写真を。2 カラムなら右半分だけにも敷けます。brightness と opacity で暗さと濃さを調整。

コードのハイライト

ts・js・sh・json・hcl・yaml・py・go・rust・html・css・diff。!! で 1 行を強調、diff は追加と削除を色分け。

スマホで縦に読める

スマホを縦に持つと、全スライドが縦に並んでスクロールで読めます。横にすればそのまま発表に戻ります。

エージェントと直す

デッキで文字を選んで「ここ直して」と頼むだけ。ippon current が表示中のスライドと行を渡し、ippon skills init が使い方を教えます。

はじめに

インストール不要。npx でその場で実行（Node.js 18.17+）。

Markdown 記法

ふつうの Markdown に、スライド用の記法を少しだけ。詳細と、すべての記法が従う決まりは ドキュメント に。

記法意味
---スライドの区切り（コードフェンス内は無視）。
::center::中央寄せの大きな 1 メッセージ。
::title::表紙。最後の行が下に沈む。
::bg=blue:: / ::size=1.5::背景色・文字サイズ倍率。
::right::2 カラム（left-wide / right-wide で 1.4:1、center で上下中央揃え）。
::background path=… brightness=0.5::背景画像。::right:: の後ろなら右半分だけ。
::qr url=…::URL の QR コード（caption で URL も表示）。
::note::以降は発表者ノート（発表者ビュー・スマホのみ）。
::http method=GET url=…::HTTP リクエストのプレイグラウンド。
-# （段落の頭）小さい注釈。
!! （行頭）コードのその行を強調。

スライドに、生の HTTP レスポンスを

API の発表やデモに。ステータス・レスポンスタイム・ヘッダー・整形した JSON を、ビルド時に Node で取得して焼き込みます。CORS に左右されず、PDF にもそのまま出ます。「再送信」でブラウザからライブで叩き直せます。

結果はもう手元にあるので、本番でデモが失敗しません。

::http method=GET \
  url=https://api.github.com/repos/under18dev/ippon-slides::
# LAN で配信し QR を表示
npx ippon-slides serve slide.md

スマホをリモコンに

ippon serve が QR を表示。読み取るとスマホがリモコンになり、ページ送り・タイマー・発表者ノートを手元で操作できます。通信は LAN 上の SSE だけ（WebSocket も外部サービスもなし）。ペアリング URL はランダムトークンで保護されます。

Markdown を保存すると、開いているデッキは変わったスライドだけを差し替えます。表示中のスライドもそのまま。

CLI

コマンドは少しだけ、既定値はそのまま使える。

ippon build <in.md> --html --pdf -o dist/HTML と PDF を作る。
ippon serve <in.md> [-p 7000]ローカルで配信し、スマホをリモコンに（QR）。
ippon init [file]サンプルのデッキを作る。
ippon build … -w保存するたびに作り直す。
ippon build … --inline画像を HTML に埋め込む。
ippon ogp <in.md>表紙を 1200×630 の共有用画像にする。
ippon current / ippon skills init表示中のスライドをコーディングエージェントに渡す。

FAQ

Markdown からスライドを作るには？

npx ippon-slides init でサンプル slide.md を作り、npx ippon-slides build slide.md --html で単一の slide.html を出力します。--- で区切り、1 枚に 1 メッセージ。

出力はオフラインで動く？

はい。CSS/JS 全部入りの 1 ファイルなので、ネットワークもサーバーも依存もなしで、どのブラウザでも開けます。

PDF に書き出せる？

はい、--pdf で。ローカルの Chrome / Chromium / Edge を使って 16:9 PDF を印刷するので、重いものを同梱しません。

スマホから操作できる？

はい。ippon serve が QR を表示。読み取ればページ送り・タイマー・発表者ノートを LAN 上の SSE で同期して操作できます。

URL を貼ったときに表紙を出せる？

はい。ippon ogp slide.md で表紙を 1200×630 の slide.png にします。frontmatter に公開先の url: を書くと、ビルドした HTML の og:image にその画像が入ります。

表示中のスライドを AI エージェントに直してもらえる？

はい。ippon serve 中に ippon current を実行すると、表示中のスライド・Markdown 上の行範囲・選択中の文字列が出ます。ippon skills init でスキルを置けば、Claude Code や Codex に「ここ直して」と頼むだけで使ってくれます。

無料でオープンソース？

はい。MIT ライセンスで npm に公開、ランタイム依存はゼロです。
